## Demo tips for this agent

- **Use the synthetic test policies** (generated by `scripts/generate_test_policies.py`) — real specimen PDFs from insurers identify the product but leave the schedule blank, so the fully-populated synthetic ones demo the full analysis (XIRR, term+SIP, verdict).
- **Show both paths**: a health policy (room-rent caps, co-pay) and a life/ULIP policy (XIRR, opportunity cost, free-look advice).
- **Test locally first** with `uv run python scripts/run_policy_file.py <policy.pdf>` — no channels needed, instant feedback.
- **The live agent** connects via `uv run python -m policydecoder.main` (email + Telegram). To exercise the full `on_message` flow, message the bot directly — the sandbox's `/v1/test-emails` endpoint is currently unreliable (422).
- **Latency**: Docling parses a 20-page PDF in ~80s on CPU. For a smooth demo, consider disabling Docling (`DOCLING_ENABLED=false`) and using the vision path, or pre-warming with the parse cache.

## SDK reference

### Setup

```bash
# Get an API key (free, no signup)
curl -s -X POST https://api.trycaspianai.com/v1/projects/sandbox \
  -H 'Content-Type: application/json' -d '{"name":"policy-decoder"}'

# .env
CASPIAN_API_KEY=comm_sandbox_...
CASPIAN_BASE_URL=https://api.trycaspianai.com
```

```bash
pip install caspian-sdk
```

### Minimal agent

```python
from caspian_sdk import CommClient

client = CommClient()
email = client.connect_email(username="policydecoder")
telegram = client.connect_telegram(bot_token="...")

@client.on_message
def handle(message):
    answer = your_logic(message.text)
    message.reply(answer)

client.listen()
```

WhatsApp, iMessage, Instagram, Facebook, voice are not live on the hosted gateway. Don't try them.

### Useful SDK features

- client.behavior_prompt() → per-channel etiquette for your system prompt
- message.typing() → keep typing indicator alive during long LLM calls
- client.listen(ack="...") → instant acknowledgement on channels without typing
- client.send_message(conversation_id, text) → proactive messages
- Rich blocks (cards, buttons) for Telegram

### Verify the agent is alive

```bash
# Check events (the agent polls these)
curl -s "https://api.trycaspianai.com/v1/events?type=message.sent" \
  -H "Authorization: Bearer $CASPIAN_API_KEY"
```

Note: the `/v1/test-emails` endpoint has been unreliable on this sandbox (422 on the telegram channel). For a reliable end-to-end check, send a real message to the bot on Telegram.
